# ECG Arrhythmia Classifier (1D-CNN + RR-MLP)

Гибридная нейросетевая система для автоматической детекции R-пиков и классификации сердечных аритмий по стандарту **AAMI EC57** на базе датасета **MIT-BIH Arrhythmia Database** в строгой пациентонезависимой постановке (*Inter-patient split*, схема de Chazal et al.).

## Ключевые особенности

* **Автономная обработка сигнала (без опоры на эталонную разметку при инференсе):**

  * Полосовой фильтр Баттерворта (0.5–40 Гц, 4-й порядок с нулевой фазой `filtfilt`) и Z-нормализация отведения `MLII`.

  * Детектор R-пиков по алгоритму **Пана — Томпкинса** (полосовая фильтрация QRS 5–15 Гц, 5-точечное дифференцирование, скользящее интегрирование 150 мс, адаптивные пороги `SPKI`/`NPKI`, рефрактерный период 200 мс и механизм `search-back`).

* **Гибридная мультимодальная архитектура (`HybridECGClassifier`):**

  * **Морфологическая ветка (1D-CNN):** извлекает признаки формы комплекса P-QRS-T из окна длиной 256 отсчётов (`96` до R-пика и `160` после при частоте дискретизации 360 Гц) $\rightarrow$ эмбеддинг размерности `128`.

  * **Ритмологическая ветка (RR-MLP):** обрабатывает 4 интервальных признака (`pre_RR`, `post_RR`, `local_RR`, `ratio_RR`) $\rightarrow$ эмбеддинг размерности `32`.

  * **Fusion-классификатор:** объединяет морфологические и временные признаки (`160` признаков) для классификации на 4 класса AAMI (`N`, `S`, `V`, `F`).

* **Борьба с дисбалансом классов и утечкой данных:**

  * Разделение пациентов строго без пересечений (`DS1` — 22 пациента для обучения и валидации через `GroupKFold`, `DS2` — 22 независимых пациента для финального тестирования).

  * Функция потерь **Focal Loss** ($\gamma = 2.0$) с весами по эффективному числу сэмплов ($\beta = 0.999$) и мягкая координатная калибровка порогов вероятностей на валидационном фолде.

## Результаты на отложенной выборке DS2 (Hold-out Test)

## Быстрый старт

### 1. Установка зависимостей

```
python -m venv .venv
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Linux / macOS:
# source .venv/bin/activate

pip install -r requirements.txt

```

### 2. Скачивание и подготовка датасета MIT-BIH

```
# 1. Загрузка сырых записей с PhysioNet в data/raw/
python -m src.data.download

# 2. Фильтрация, детекция R-пиков и генерация ds1_train.npz / ds2_test.npz
python -m src.data.dataset

```

### 3. Обучение и оценка модели

```
# Обучение гибридной модели на DS1 с подбором калибровочных множителей
python -m src.train

# Финальная оценка на отложенных пациентах DS2 и генерация reports/ds2_metrics.json
python -m src.evaluate

```

Для быстрой проверки работоспособности пайплайна без скачивания датасета доступен режим `--smoke-test`:

```
python -m src.train --smoke-test
python -m src.evaluate --smoke-test

```

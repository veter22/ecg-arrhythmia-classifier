# ECG Arrhythmia Classifier

Сквозной пайплайн глубокого обучения на PyTorch для автоматической детекции R-пиков и классификации сердечных аритмий по одноканальной ЭКГ (отведение MLII) в соответствии со стандартом **AAMI EC57** на базе **MIT-BIH Arrhythmia Database**.

---

## Архитектура и методология

1. **Автономная предобработка ЭКГ и детектор R-пиков (`src/data/filtering.py`):**
   * Полосовая фильтрация Баттерворта (`0.5–40 Гц`) и локальная робастная нормализация скользящим окном (`4 с`, медиана + MAD), устойчивая к единичным амплитудным артефактам.
   * Автономный поиск R-пиков по адаптивному алгоритму **Пана — Томпкинса** (ориентированная производная, робастная инициализация порогов, отсеивание высоких T-зубцов по крутизне фронта и search-back с проверкой рефрактерного периода `200 мс`).
   * Нарезка морфологических окон длиной `256` отсчётов (`96` до R-пика и `160` после при частоте `360 Гц`) и расчёт `6` физиологических признаков вариабельности ритма: `pre_rr`, `post_rr`, `local_rr` (по 8 предшествующим интервалам без утечки текущего удара), `pre_rr / local_rr`, `post_rr / local_rr` и асимметрия ритма.

2. **Гибридная нейросетевая архитектура `1D-Dilated-ResNet + RR-MLP` (`src/models/hybrid_cnn.py`):**
   * **Морфологическая ветка:** свёрточные остаточные блоки с дилатацией (`dilation = 1, 2, 4`, рецептивное поле `~220` отсчётов / `~610 мс`) и 3-зонным темпоральным пирамидным пулингом, сохраняющим порядок фаз сердечного цикла `P — QRS — ST-T`.
   * **Ритмологическая ветка (`RR-MLP`):** полносвязная сеть с BatchNorm и Dropout, кодирующая 6 признаков RR-интервалов.
   * **Классификация AAMI EC57:** 4 целевых класса — `N` (норма), `S` (наджелудочковая экстрасистола), `V` (желудочковая экстрасистола), `F` (сливной удар).

3. **Валидация и работа с дисбалансом классов (`src/train.py`):**
   * Строгое пациентонезависимое разделение по протоколу **de Chazal**: 22 пациента (`DS1`) используются для 5-фолдовой кросс-валидации (`StratifiedGroupKFold`) с аугментациями сигнала, а 22 абсолютно новых пациента (`DS2`) — исключительно для финального тестирования.
   * Функция потерь **Focal Loss** (`gamma = 2.0`) с весами по эффективному числу сэмплов (`beta = 0.9999`) и **post-hoc подбор весов решающего правила (prior tuning)** на out-of-fold предсказаниях всей выборки `DS1`.

## Результаты на отложенной выборке DS2 (22 новых пациента)

### 1. Автономный детектор R-пиков Пана — Томпкинса (`reports/detector_ds2_stats.json`)
* **Эталонных ударов AAMI в DS2:** `49 705`
* **Найдено детектором (TP / FP / FN):** `49 335` / `265` / `370`
* **Sensitivity (полнота):** **`99.26%`**
* **PPV (точность):** **`99.47%`**

### 2. Классификация аритмий ансамблем из 5 фолдов (`reports/ds2_metrics.json`)

Оценка выполнена на `49 291` сопоставленном кардиоцикле:
* **Raw Macro-F1 (без пороговых весов):** `0.4825`
* **Post-hoc Tuned Macro-F1 (N / S / V / F):** **`0.4853`**
* **Post-hoc Macro-F1 по основным классам (N / S / V):** **`0.6383`**
* **Подобранные веса решающего правила `[N, S, V, F]`:** `[1.0, 1.0971, 0.9466, 0.7193]`

| Класс AAMI | Precision | Recall | F1-score | PR-AUC | Support |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **`N` (Норма)** | `0.9650` | `0.9178` | `0.9408` | `0.9833` | `44 071` |
| **`S` (Наджелудочковые)** | `0.2811` | `0.1667` | `0.2093` | `0.2037` | `1 818` |
| **`V` (Желудочковые)** | `0.6441` | `0.9410` | `0.7647` | `0.9445` | `3 017` |
| **`F` (Сливные)** | `0.0159` | `0.0779` | `0.0264` | `0.0130` | `385` |

> **Примечание по классу `F` (Fusion beats):** класс `F` составляет менее `0.8%` выборки (`385` ударов) и морфологически является промежуточным между `N` и `V`. Повышение чувствительности к `F` и `V` через весовую схему `beta = 0.9999` увеличило полноту обнаружения желудочковых аритмий до `94.1%` (`PR-AUC = 0.9445`), но привело к смещению части нормальных и наджелудочковых ударов в `V` и `F`. Детальная матрица ошибок и разбор по всем 22 пациентам `DS2` доступны в `reports/figures/confusion_matrix.png`, `reports/ds2_metrics.json` и `notebooks/error_analysis.ipynb`.

## Структура проекта

```text
ecg-arrhythmia-classifier/
├── checkpoints/                  # Сохранённые веса ансамбля (best_model.pt)
├── configs/
│   └── config.yaml               # Параметры фильтрации, модели и обучения
├── data/
│   ├── raw/mitbih/               # Сырые записи MIT-BIH (.hea, .dat, .atr)
│   └── processed/                # Сформированные датасеты ds1_train.npz и ds2_test.npz
├── notebooks/
│   └── error_analysis.ipynb      # Визуальный разбор ошибок по классам и пациентам DS2
├── reports/
│   ├── figures/
│   │   └── confusion_matrix.png  # Матрица ошибок (абсолютная и нормированная)
│   ├── baselines_comparison.json # Сравнение с ML-бейзлайнами и абляция RR-ветки
│   ├── detector_ds2_stats.json   # Метрики автономного детектора R-пиков
│   └── ds2_metrics.json          # Полный отчёт по классам и 22 пациентам DS2
├── src/
│   ├── data/
│   │   ├── download.py           # Атомарная загрузка MIT-BIH с PhysioNet
│   │   ├── filtering.py          # Фильтрация Баттерворта и детектор Пана — Томпкинса
│   │   └── dataset.py            # Формирование DS1/DS2 и извлечение 6 RR-признаков
│   ├── losses/
│   │   └── focal_loss.py         # Focal Loss с весами эффективного числа сэмплов
│   ├── models/
```

## Быстрый старт

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Загрузка MIT-BIH Arrhythmia Database и генерация выборок DS1 / DS2
python -m src.data.download
python -m src.data.dataset

# 3. Обучение ансамбля из 5 фолдов и OOF-подбор весов решающего правила
python -m src.train

# 4. Оценка на отложенных пациентах DS2 и сравнение с бейзлайнами
python -m src.evaluate
python -m src.baselines
```
